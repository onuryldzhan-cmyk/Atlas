# CFG-001 plan: typed configuration and startup validation (draft, 2026-09-28)

The owner picked CFG-001 as the next roadmap item (registry v5.18: feature expansion limited to the next roadmap phase). This file is a plan only. Implementation starts once the owner approves it.

## Current state (FACT, inspected)

- There is no settings file. The execution mode is hard-coded as `execution_mode="PAPER"` at `main.py:478`, and EXP-001 is opted in at `main.py:479`.
  - This resolves the Phase 2–3 UNKNOWN about whether a settings key can override PAPER: **no key can.**
- The configuration surface consists of:
  - environment variables, each read and checked separately:
    - `ATLAS_STATE_DIRECTORY`, `ATLAS_MARKET_ARCHIVE_DIRECTORY` and `ATLAS_EVIDENCE_DIRECTORY` in `core/application.py`;
    - the supervisor epoch, restart count and heartbeat file;
    - the supervisor log directory;
  - `config/instrument_rules.json`;
  - `core/secret_provider.py`.
- There is no single place that validates all of this before Atlas starts.

## Smallest correct change

1. **`core/atlas_config.py`**
   - A frozen `AtlasConfig` holding every value above.
   - `load_config(environ)` collects **all** errors in one pass instead of stopping at the first one.
   - It reuses the existing resolve functions, so behaviour does not change.
2. **Invariant:** `execution_mode` must be `PAPER`. Anything else is refused while `live_authority=DENIED`.
3. **`main.py`** loads the config once, before taking the instance lock, and builds `AtlasApplication` from it. An invalid config stops Atlas before it touches any state.
4. **`tools/show_config.py`** (read-only) prints the effective configuration without any secrets. It gives the owner a pre-flight view.
5. **Tests** cover:
   - each invalid value;
   - several invalid values at once, all of them reported;
   - a non-PAPER mode refused;
   - secrets never printed;
   - the current `main.py` behaviour, byte-for-byte for a valid environment.

**Out of scope:**
- any new setting;
- a settings file;
- changing any default;
- live, shadow or exchange configuration.

## Owner decisions needed

- **D1: exit code for an invalid configuration.** A new code, 78 CONFIG_INVALID, that the supervisor never restarts, like 75/76 (recommended: restarting cannot fix a bad setting). The alternative is to keep exit 1, which the supervisor retries within its budget.
- **D2: an unknown `ATLAS_*` environment variable**, for example a typo. Refuse to start (recommended: a typo would otherwise be silently ignored) or only warn.

## Classification

This is CRITICAL, because it touches startup and the paper/live boundary. It goes through the full gate: implement, test, self-review, regression, independent audit, fix, re-test. Registry successor v5.20.
